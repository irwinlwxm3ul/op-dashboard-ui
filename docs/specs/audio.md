# Module spec: audio

Owned paths: src/client/audio/** and tests/audio.test.ts

- MODULE: Audio engine (src/client/audio) — exact API in ARCHITECTURE.md (singleton export named audio). Browser code (WebAudio). It must be a silent no-op that never throws when AudioContext is unavailable (Node tests, headless) or before init().

- Sound is a huge part of game feel — make it punchy and believable. Synthesize gunshots procedurally and pre-render them once into AudioBuffers with OfflineAudioContext at init (3 variations per kind for variety): layered sharp transient (short highpassed noise click), body (bandpassed/lowpassed noise with fast decay, character per weapon kind: pistol snappy, smg tight and rapid, rifle full crack, shotgun boomy, dmr and sniper heavy crack + long rolling tail), low thump (sine sweep ~120->40 Hz), and an outdoor tail (long lowpassed noise decay, slapback echo for snipers). Distant variants: for remote shots compute distance to listener; delay = distance / SPEED_OF_SOUND; gain by inverse-distance law with rolloff until inaudible at the weapon loudness range; lowpass cutoff falls with distance (e.g. 18 kHz near to ~700 Hz at 800 m) and tail emphasised; random pitch +-4 percent. Local player shots: no delay, slightly louder, stereo centred, plus a mechanical action layer.

- Spatialisation: stereo panning computed from listener yaw (setListener) and source direction (StereoPannerNode, cheap) plus distance attenuation; voice limiting (max ~40 concurrent one-shots; drop the quietest / farthest).

- Other sounds: dryFire click; reload phases (mag out, mag in, bolt cycle, shell insert) as synthesized mechanical clicks/clacks; weaponSwitch (use Kenney weapon_change.ogg); impacts by material (dirt/grass thud, concrete/rock crack+ricochet chance, metal ping, wood knock, water splash, flesh wet thud, armor clank) at position with distance attenuation; bulletCrack (near-miss supersonic snap: sharp crack + whizz); footsteps per SurfaceMaterial (grass soft swish, dirt/sand crunch, wood hollow knock, concrete/road click, metal clank, water splash) intensity scales with sprint/crouch, remote footsteps attenuate quickly (audible ~35 m); jump (Kenney jump_a/b/c.ogg variants, quiet), land (Kenney land.ogg + thump scaled by intensity); hitmarker kinds: body = crisp tick, head = brighter metallic ding, armor = duller clank tick, knock = deeper double tick, kill = satisfying confirm chime (layered) — hitmarkers are UI (not spatial) and must be clearly distinguishable; hurt (Kenney enemy_hurt.ogg + low thud scaled by amount); armorBreak (glassy crack); explosion (big layered noise + sub thump + long tail, distance delay and lowpass, also Kenney enemy_destroy.ogg layer); heal (bandage rip / syringe click); pickup (cloth rustle); ui sounds (click, hover, ready, start, countdown beep, error buzz, zone warning siren-ish tone, win fanfare, lose sting) synthesized.

- Loops: setWind(intensity 0..1) noise through bandpass with slow modulation for freefall/parachute; setZoneProximity(insideBlue, intensity) electric hum/crackle when outside the safe zone; engine(id) returns a handle whose update(pos, rpm, throttle, local) drives an engine loop (2-3 oscillators sawtooth/square detuned through lowpass + some noise, frequency from rpm, gain from throttle, distance attenuation); stop() fades out and frees nodes.

- Assets available under /assets/sounds/: blaster.ogg, blaster_repeater.ogg, enemy_attack.ogg, enemy_destroy.ogg, enemy_hurt.ogg, jump_a.ogg, jump_b.ogg, jump_c.ogg, land.ogg, walking.ogg, weapon_change.ogg (Kenney CC0). Load with fetch + decodeAudioData lazily in init(); failures must be tolerated (fallback to synthesized).

- Buses: master -> compressor/limiter (DynamicsCompressor) -> destination; sfx bus, ui bus with volumes from setSettings. update(dt) handles loop smoothing. Keep CPU light: one-shots use pre-rendered buffers with BufferSource + a few nodes.

- Tests (tests/audio.test.ts, Node environment, no AudioContext): importing the module and calling every API method (before and after init()) never throws and init resolves.
