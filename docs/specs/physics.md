# Module spec: physics

Owned paths: src/shared/physics/** and tests/physics.test.ts

- MODULE: Physics (src/shared/physics): character controller, drop (freefall/parachute) movement, raycasts, hitboxes, generic collision helpers — exact API in ARCHITECTURE.md.

- The World object comes from src/shared/world (being written concurrently by another agent). Only rely on the World interface in types.ts. For your tests, build a small hand-made fake World object (flat or sloped heightmap + a few boxes + trees + rocks, with simple query implementations) inside the test file — do not depend on generateWorld.

- Character controller (stepCharacter, modes ground and swim): vertical cylinder radius PLAYER_RADIUS, height by stance (STANCE_HEIGHT). Movement basis from intent.yaw using math.ts forward/right. Target speed from MOVE_SPEED (sprint only when standing, mz > 0.3 and not walking; crouch/prone/slowWalk speeds; downed crawl), multiplied by intent.speedMul. Accelerate toward target with GROUND_ACCEL and apply GROUND_FRICTION when no input (snappy but not instant; must feel tight). Air control with AIR_ACCEL. Gravity GRAVITY*CHAR_GRAVITY_MUL. Jump with JUMP_VELOCITY, coyote time COYOTE_TIME (body.airTime) and input buffer JUMP_BUFFER_TIME (body.jumpBuffer), not when prone/downed; jumping from crouch stands up. Stance changes require headroom (canStand); report stanceBlocked. Collisions: XZ circle vs WorldBox AABBs (with vertical overlap test against body span), tree trunk cylinders (TreeDef r, height h*0.6), rocks as cylinders (r, h). Step-up onto boxes up to STEP_HEIGHT (stairs!), step-down snapping when walking down stairs/slopes so the body does not bounce, standing on box tops (floors, roofs, crates) as ground, ceilings stop upward motion. Terrain via world.heightAt; slopes steeper than MAX_SLOPE_DEG make the body slide and block walking up. Sub-step so no step moves more than ~0.25 m (no tunneling through 0.25 m walls even at high speed). Map bounds clamp to half - 1. Swim: when water depth (WATER_LEVEL - ground) > 1.3 m switch to swim: body pos.y held at WATER_LEVEL - 1.25 (head above water), MOVE_SPEED.swim, no jump, stance forced stand; leave swim when depth < 1.1 m. Track fallSpeed and emit landed with landSpeed. Deterministic and only mutates body/out.

- stepDrop (modes freefall/parachute): freefall vertical speed eases to FREEFALL_SPEED (mz > 0 dives toward FREEFALL_DIVE_SPEED and increases forward speed; mz < 0 slows forward), horizontal velocity eases toward intent direction up to FREEFALL_HORIZONTAL; parachute: descent PARACHUTE_DESCENT (forward input speeds descent to ~9 m/s and forward speed, back input slows to ~4.5 and forward speed), horizontal up to PARACHUTE_HORIZONTAL with constant forward drift along yaw, smooth easing. Land on terrain or box tops (roofs) via groundAt-like checks and box collision; on landing set mode ground (or swim if deep water), zero vertical velocity, emit landed + landSpeed. Clamp to map bounds.

- eyePosition: eye height from EYE_HEIGHT by stance (vehicle mode: seated eye ~1.1 above pos, freefall/parachute standing); lean offsets eye sideways by 0.35*lean along right(yaw) and lowers it by 0.05.

- raycastWorld: nearest hit among terrain (heightmap march with step <= cell/2 then binary refinement), water surface (y = waterLevel when ray crosses it over water, kind water), boxes with blocksBullets (only those along the ray: traverse in segments/grid cells, do not test all boxes), tree trunks, rocks (approximate as cylinders or ellipsoids). Returns RayHit with point, normal, kind, material, id (box id) — fill into out when provided. Must handle rays up to 1200 m efficiently (bots call lineOfSight a lot; target < 50 microseconds for a 100 m ray on a typical world). lineOfSight ignores water.

- Hitboxes: buildHitboxes from pose: standing: head sphere (r ~0.13 at ~1.65 m), torso capsule (r ~0.22, 0.95-1.45 m) part body, pelvis sphere body, two leg capsules (limb, r ~0.11), two arm capsules (limb). Crouch scaled/lowered, prone and downed lying along facing direction (head forward), lean shifts/tilts upper body sideways, mode vehicle = seated (torso/head only, around eye ~1.1), mode plane = no hitboxes (return empty), dead = empty. raycastHitboxes returns nearest {t, part}. rayCapsule must be exact (ray vs capsule = min of ray vs infinite cylinder clipped to segment and ray vs end spheres).

- collideCircleXZ: push a circle (pos x/z, radius, vertical span y0..y1) out of boxes/tree trunks/rocks; returns push normal and depth. Used by vehicles too.

- Tests (tests/physics.test.ts) with a fake world: walking reaches speed with acceleration (not instant), stops with friction; cannot pass through a 0.25 m wall at sprint; climbs a staircase of 0.3 m steps; cannot step onto a 0.8 m box; jump height approx v^2/(2g); coyote and buffer work; crouch blocked under low ceiling; swim transition; freefall terminal speed and parachute descent speeds; landing on a roof box; raycast hits terrain/box/tree correctly and returns nearest; lineOfSight blocked by wall; capsule ray exact vs brute force sampling; head hits classify as head; prone hitboxes lie horizontally; determinism (same inputs => identical body).
